# ЭНЕРГИЯ (ОБНОВЛЁННАЯ)

## 1. ИСТОЧНИКИ
- солнце;
- ветер;
- биогаз;
- атмосферное электричество;
- малый реактор;
- термояд (в будущем).

## 2. ПРИНЦИПЫ
- чисто;
- стабильно;
- своё;
- без нефти.

## 3. ХРАНЕНИЕ
- суперконденсаторы;
- маховики;
- водород;
- тепловые баки.

## 4. УПРАВЛЕНИЕ
- ИИ следит за балансом;
- переключает источники;
- экономит.

## 5. БЕЗОПАСНОСТЬ
- реактор — только с пассивной защитой;
- физический ключ;
- аварийные контуры.

## ИТОГ
Энергия — это кровь города.
Она должна быть своей.
