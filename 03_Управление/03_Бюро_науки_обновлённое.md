# БЮРО НАУКИ (ОБНОВЛЁННОЕ)

## 1. ЧТО ДЕЛАЕТ
- направляет;
- оценивает;
- хранит;
- защищает.

## 2. НАПРАВЛЕНИЯ
- физика;
- химия;
- биология;
- энергия;
- космос;
- материалы.

## 3. ПРАВИЛА
- наука — для жизни;
- знание — для всех;
- оружие запрещено;
- скрывать нельзя.

## 4. ЭТИКА
- лечение — да;
- улучшение — с одобрения;
- клоны — нет.

## ИТОГ
Наука — это свет.
Но у света есть границы.
